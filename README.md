# Weird Science

Weird Science is a private, local-first AI companion platform.

It focuses on:

* Inspectable memory
* Real relationship progression
* Emotional continuity
* Dignified, non-exploitative design

## Core Idea

This is not a chatbot.

This is a companion that:

* Remembers your life
* Evolves over time
* Helps you through a chapter
* And allows the relationship to change or end well

## Tech Stack (Planned)

* Tauri (desktop shell)
* React + TypeScript
* SQLite (local storage)
* Ollama (local AI memory engine)
* Hosted LLM (conversation layer)
